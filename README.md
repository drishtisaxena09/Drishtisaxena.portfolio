# Drishti Saxena | Data Analyst Portfolio

A professional portfolio website showcasing data analytics projects, technical skills, and business intelligence capabilities.

## Live Demo

**Portfolio:** https://drishtisaxena.netlify.app/

## Overview

This portfolio serves as a centralized platform to present analytical expertise, project work, and technical competencies in data analytics and business intelligence. The website highlights practical experience with data visualization, reporting, and data-driven problem solving.

## Key Features

* Responsive and modern user interface
* Professional profile presentation
* Technical skills showcase
* Project portfolio section
* Resume integration
* Contact and social links
* Optimized for desktop and mobile devices

## Configuration

To personalize the portfolio:

1. Update profile information in `assets/js/main.js`
2. Replace images in `assets/img/`
3. Add your resume as `assets/docs/resume.pdf`
4. Update project information in `index.html`
5. Configure social and professional links

## Deployment

The website can be deployed using:

* GitHub Pages
* Netlify
* Vercel

No build process or additional dependencies are required.
